# HDMI2 彩条工程检查记录 — 2026-11-08

## 结论

检查实际工程源码、XDC、时钟 IP 和已有布局布线报告，并以 Vivado/XSim 2018.3 补做行为仿真。未发现当前数据通道、串行位序、显示扫描或引脚分配的明确功能错误；仍有复位结构与 PS7 警告，且未完成真实显示器、电气与完整时序仿真验证。不能将本检查表述为已经点亮屏幕或所有警告清零。

## 已核对

- 顶层 hdmi_test_top；器件 xc7z020clg484-2。
- sys_clk=Y9、50 MHz；S0 reset_n=P17，顶层取反转为内部高有效复位。
- HDMI2 数据 0=P:Y4/N:AA4；数据1=P:AB5/N:AB4；数据2=P:AB7/N:AB6；时钟=P:Y6/N:Y5。实现 I/O 报告与 XDC 一致，差分输出为 TMDS_33。
- MMCM D=4、M=59.375，输出分频10和2；实际像素74.21875 MHz，高速371.09375 MHz，严格1:5。
- 扫描1650×750；有效1280×720；正极性同步；实际刷新率约59.97475 Hz，非精确60 Hz。
- 三个编码器共享视频节奏且独立保存 disparity；编码输出由串行器在后续装载边沿接收，各数据通道延迟一致。
- 四个10位主从串行器：三个数据通道和一个固定1111100000时钟通道。

## 修正与备份

1. video_timing.v 缺失timescale。在独立编译顺序下XSim报告XSIM 43-4099。添加与其他模块一致的 `timescale 1ns / 1ps；不改变综合电路功能。
2. tb_video_timing.v 在时间0读取DUT，早于异步复位非阻塞赋值生效，产生“Counters not zero during reset”假失败。仅在复位分支的检查前等待1 ps，整帧测试随后通过。

修改前文件保存在 backups/audit_20261108/。未改动功能算法、引脚、电气标准、IP参数或全局配置。没有重建整个工程、生成或下载bitstream。

## 仍需处理或接受的边界

- LUTAR-1：sys_reset | ~clk_locked 经组合逻辑驱动复位同步寄存器的异步置位端。属于毛刺敏感结构警告；当前行为仿真通过不能证明实物无毛刺。尚未改变该结构，也没有豁免警告。建议在后续复位专题中单独改进并验证。
- ZPS7-1：Zynq工程未例化PS7。目前功能链只使用PL外部参考时钟与PL I/O，不使用PS时钟、AXI或DDR；但这不足以证明所有上电/PS默认配置条件均无影响。未自动添加PS、未降低DRC严重级别，板级启动仍需验证。
- 未实现EDID读取/HPD驱动策略，固定输出720p近60 Hz；具体Dell显示器的输入模式支持尚未核实。
- 实现报告属于本次添加timescale之前的现有运行；此次没有修改功能逻辑，但源码时间已变化，Vivado可能将运行标为需更新。最终生成文件前应正常更新对应运行并复查。
- 实物底板没有单独测量；引脚依据为已核对的厂家原理图与引脚表，未进行通断或信号完整性测量。
